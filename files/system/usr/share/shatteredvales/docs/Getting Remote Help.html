Getting Remote Help

This computer can let a family member or friend you trust help you over the internet, as if they were sitting next to you. It uses a free service called Tailscale, which is already installed. Nothing is shared until someone sets it up.

For the person being helped

  1. Ask your helper to follow the steps below. They will need about ten minutes with you, in person or on the phone, the first time.
  2. Only let someone you trust do this. Once it is set up, they can reach this computer whenever it is switched on.

For the helper

  1. Make a free Tailscale account at login.tailscale.com/start, and install Tailscale on your own computer from tailscale.com/download.
  2. On this computer, open Terminal from the app list and type:
    sudo tailscale up --ssh
    It asks for this computer's administrator password, then shows a web address. Open that address and sign in with your Tailscale account.
  3. From your own computer you can now connect with ssh <their username>@<this computer's name>, or see it in your Tailscale admin console. Tailscale's guide: Install Tailscale.
  4. To stop remote help at any time: sudo tailscale down (pause) or sudo tailscale logout (remove).

Updates install themselves. If the computer asks to restart, save your work and restart. If something stops working, the System Update app can go back to the previous version.
